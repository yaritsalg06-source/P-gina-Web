En este proyecto he creado una página para mostrar diferentes lugares de interés de La Gomera. Empecé haciendo la página principal con varios pueblos y después fui añadiendo más secciones como Restaurantes y Hoteles. 
Toda la web sigue el mismo estilo porque uso un único archivo CSS que controla el diseño de todas las páginas. Las imágenes, los textos y la estructura están organizados en carpetas para que todo quede limpio y ordenado.
En la parte de JavaScript añadí varias funciones que hacen que la web sea más interactiva. Lo primero que programé fue un mensaje de bienvenida que solo aparece cuando se refresca la página de inicio. Esto lo hice comprobando si la ruta del archivo contiene la palabra “index”, así evito que el mensaje salga cuando el usuario entra en otras páginas,también añadí dos funciones para ocultar y mostrar todas las imágenes de la página, estas funciones recorren todas las etiquetas de imagen con un bucle y cambian su visibilidad, después añadí un contador que permite sumar, restar y reiniciar. El contador cambia de color según si el número es positivo, negativo o cero, y además se guarda automáticamente en el almacenamiento local del navegador para que no se pierda al recargar la página.
En una de las páginas añadí una función que cambia el texto de un párrafo cuando se pulsa un botón. Esto lo hice seleccionando el elemento por su id y cambiando su contenido con JavaScript., también añadí una función para la sección de restaurantes donde el usuario puede escribir un nombre y al pulsar un botón aparece un mensaje que muestra lo que ha elegido.
En la página de hoteles añadí algo nuevo, coloqué tres hoteles de La Gomera y programé una función que muestra información diferente según el hotel que el usuario seleccione. Cada botón llama a la misma función pero enviando un valor distinto, y según ese valor se muestra la información correspondiente. Además, el texto aparece con un fondo y un estilo diferente para que destaque.
Con todo esto, la web combina HTML para la estructura, CSS para el diseño y JavaScript para darle vida. Las funciones que añadí permiten que el usuario interactúe con la página y hacen que el proyecto sea más completo y dinámico.
